# App icon

A glass shopping bag with an AI spark: shopping, done by agents.

- `background.svg`, `bag.svg`, `spark.svg`: the three layers, 1024×1024, for Apple's Icon Composer. Drag them in
  bottom to top (background, bag, spark) to get the Liquid Glass `.icon`.
- `icon.svg`: a flattened glass version for the web (favicon, sidebar logo, PDF header).
- `icon-1024.png`: rendered from `icon.svg`.
